# MediCat USB — Linux installer

Bash installer for MediCat USB on Linux: **`Medicat_Installer.sh`**. Free software under the GNU GPL-3.0 ([`LICENSE`](LICENSE)), without any warranty; the repository as a whole is AGPL-3.0 ([`../LICENCE`](../LICENCE)).

Website: [medicatusb.com](https://medicatusb.com/) · Discord: [url.medicatusb.com/discord](https://url.medicatusb.com/discord)

## Quick start

One line: download the script from this repository into the current directory and run it interactively. It is self-contained, so nothing else from the repository is needed.

```bash
curl -fsSLO https://raw.githubusercontent.com/26zl/medicat_installer/main/linux/Medicat_Installer.sh && chmod +x Medicat_Installer.sh && ./Medicat_Installer.sh
```

Or clone the repository (the script lives in `linux/` next to the Windows installer):

```bash
git clone https://github.com/26zl/medicat_installer.git
cd medicat_installer/linux
chmod +x Medicat_Installer.sh
./Medicat_Installer.sh              # interactive, same flow as before
```

Headless use mirrors the Windows CLI:

```bash
./Medicat_Installer.sh --install --drive /dev/sdb --yes              # wipe sdb, install Ventoy + MediCat, verify
./Medicat_Installer.sh --install --drive /dev/sdb --yes --extras all --fs exfat --no-secure-boot
./Medicat_Installer.sh --verify --drive /dev/sdb                     # MD5-check an existing stick, repair from the archive
./Medicat_Installer.sh --verify --path /media/$USER/Medicat          # same, for an already mounted stick
./Medicat_Installer.sh --extras systemrescue,gparted-live --drive /dev/sdb
./Medicat_Installer.sh --list-extras                                 # catalog of optional boot images
./Medicat_Installer.sh --help
```

Exit codes: `0` ok, `1` error, `2` bad arguments, `4` cancelled, `5` verification found failures.

## Compatibility

Ubuntu · Debian · Arch · CachyOS · Fedora · CentOS / AlmaLinux / Rocky · Void · Alpine · NixOS (and similar). Needs bash 4+, GNU coreutils and util-linux (`lsblk`, `findmnt`, `mountpoint`), so it does not run on FreeBSD or macOS.

## Requirements

* Terminal access
* Basic Linux knowledge (disks, mounts, package managers)
* Network access to install packages and download Ventoy / MediCat

The script installs or uses packages such as `wget`, `7zip`/`p7zip` (`7z`), `ntfs-3g` / `ntfsprogs` (`mkntfs`), `dosfstools`, `parted`, and `aria2` when needed (`aria2c` speeds up downloads; `wget` or `curl` are used when it is missing).

## What it does

1. Resolves and installs dependencies for your distribution
2. Downloads and extracts Ventoy (latest, `--ventoy-version X.Y.Z`, or a local `--ventoy-tar`)
3. Finds `MediCat.USB.v21.12.7z` (or the Google Drive split set) beside the script, or downloads it from the mirrors / BitTorrent
4. Verifies the archive SHA-256 hash
5. Installs Ventoy on the chosen disk, formats the data partition (NTFS by default, `--fs exfat` optional) and extracts MediCat onto it
6. MD5-verifies every file against `MedicatFiles.md5` and re-extracts the ones that failed
7. Offers extra boot images from the catalog (`spec/extras.json`), downloaded with checksums into `Extras/<category>/`. `--extras all` is about 40 GB and only fits next to MediCat on a 128 GB stick; `--list-extras` prints the sizes, so pick ids on a 64 GB one

Mirrors, hashes, sizes and the extras catalog come from the shared [`spec/`](../spec/README.md); the block between `# BEGIN GENERATED SPEC` and `# END GENERATED SPEC` in the script is generated by `tools/gen_spec.py`, so edit the JSON, not the block.

## Contributing

Improvements to the Linux installer are welcome:

* Join the Discord: https://url.medicatusb.com/discord
* Fork this project and open a pull request against **`main`** (the script lives in `linux/`)
* Run `bash tests/linux/smoke_test.sh` before sending changes (needs `7z` and `wget` or `aria2c`; `MEDICAT_TEST_NETWORK=0` skips the download test)
* `sudo bash tests/linux/loop_install_test.sh` runs a full `--install` against a 32 GiB sparse loop device (Ventoy, NTFS format, extract, verify); it needs root and downloads Ventoy unless `MEDICAT_TEST_VENTOY_TAR` points at a local tarball
